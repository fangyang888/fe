# 预测特别码：三色选两色

每期开奖前选择两种颜色，特别码属于其中任意一种即成功。仍用2026年第1～266期快照；不等同于排除两个尾数，也不是排除两种颜色。

## 颜色与基线

项目API的numberInfos记录经核对：266期共1862条颜色记录一致，49个号码全部覆盖，无冲突；红17个、蓝16个、绿16个。这一数量与[香港赛马会颜色说明](https://campaigns.hkjc.com/2026-marksix/en/funfacts)一致，但本实验数据仍来自项目默认history接口，并非替换成香港开奖数据。

均匀1～49开奖时，红＋蓝与红＋绿各33/49＝67.35%，蓝＋绿32/49＝65.31%。从三种组合等概率随机选一组，平均命中率2/3≈66.67%。颜色类别少不意味着信息更多或命中率接近95%。

## 回测

前146期初始化；147～206期选规则，优先验证成功次数，同分比较三个20期分段的最差成绩，再同分按声明顺序；207～266期只作历史检验。每次先输出两色再学习结果。

| 方法 | 验证命中 | 后60期命中 | 对应理论基线 |
|---|---:|---:|---:|
| 固定红＋蓝（验证选定） | 45/60 | 38/60（63.33%） | 67.35% |
| 固定红＋绿 | 34/60 | 45/60（75.00%） | 67.35% |
| 固定蓝＋绿 | 41/60 | 37/60（61.67%） | 65.31% |
| 近30期颜色频率 | 39/60 | 43/60（71.67%） | 67.21% |
| 近100期颜色频率 | 35/60 | 38/60（63.33%） | 67.11% |
| 上一期颜色转移 | 40/60 | 39/60（65.00%） | 66.84% |
| 颜色遗漏条件 | 37/60 | 43/60（71.67%） | 67.14% |
| 上一期普通号颜色分布 | 36/60 | 46/60（76.67%） | 66.94% |
| 频率、遗漏、转移综合 | 32/60 | 42/60（70.00%） | 67.11% |

所选固定红＋蓝后60期成功38次、失败22次，最长连续失败4期。描述性95% Wilson区间50.68%～74.38%，不校正反复研究和选择。

所有方案使用同一快照和时段；这批历史已经反复用于其他目标，不能视为新独立测试。这里报告的比例不是下一期保证。

截至266期，所选模型针对267期的快照输出为红＋蓝。这是旧快照的实验结果，不是实时推荐。
