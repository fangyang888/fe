# 仅使用2026年：排除6个的完整比较

只使用2026年第1～266期，共266期；2025年数据不进入预热、特征、初始化、训练和逐期更新。16个配置的评分方法和超参数均沿用此前固定版本，不重新搜索参数。

## 结果

根据2026年第147～206期选择 **直接排序 C=0.2（direct-rank-c0.2）**。第207～266期中，6个全部排除成功 **54/60（90.00%）**，失败 **6期**。随机排除6个的理论基线是43/49＝**87.76%**。

95% Wilson区间79.85%～95.34%；相对随机基线的单侧二项检验p=0.3869。这段样本没有足够证据证明稳定超过随机基线。

## 时间划分

- 训练：第1～146期；前30期仅用作特征预热，监督模型有116个训练目标。
- 验证：第147～206期，60期，仅用于选配置，并列按原声明顺序。
- 检验：第207～266期，60期，先预测再学习已揭晓结果。
- 每期固定先筛20个再取6个；不跳过失败期。六模型共同筛选保留原来的两阶段不同评分标准。
- 历史数据已被前面的实验查看，属于探索性复用，不是新的独立测试。
