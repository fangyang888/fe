# 双锚点留档实战

`/fe/kill/dual-linear-anchor` 默认请求最新连续数据。后端首次读取时，将下一期的四种预测保存到独立文件；已经在数据库中的期次、研究模式和缺期数据不生成预测留档。

刷新页面会结算已入库开奖的留档，并保存下一期。未访问页面的期次不补录；没有定时任务。最新已开奖期只作为输入，不能事后加入真实实战分母。零已结算样本显示“—”。

特别码未出现是预测号码不等于第7位；与全部7码不包含预测号码分别统计。显示的是样本比例，不是未来概率保证。

## 存储

设置 `DUAL_LINEAR_LEDGER_DIR` 为持久化绝对目录。默认使用服务启动目录下的 `data/dual-linear-ledger`，按规则版本分目录。生产环境和多进程必须指向同一个持久化文件系统；重启、部署应保留这个目录。

预测包含目标期、输入截止期、保存时间、输入哈希、版本、四种预测及所选基础公式。临时完整文件通过独占硬链接原子发布，刷新不会覆盖。结算也采用独占发布；历史开奖后来修订时保留初次结算并提示修订。

这能验证“数据库收录开奖前已保存”，但若数据库上游滞后，不能单凭该时间戳证明是在实际开奖前。页面明确标注这一边界。若需要独立认证的开奖前实战，仍需可靠开奖时间来源及外部时间戳。

当前参考页仅按固定期号切分历史复算；本页实战分母只包含已保存的预测，不复用那种历史切分方式。
