# StatusAlert

美柚通用的加载 / 提示 / 异常 等缺省状态占位组件

<Alert type="info">
注意，非 full 模式下，StatusAlert 通过 `flex: 1` 撑满父容器，因此父容器需要是 `display: flex`。
</Alert>

<code src='./demos' phone />

## 基本用法

StatusAlert 具有十种类型，具备不同的状态样式:

- `NONE`: 无样式
- `LOADING`: '努力加载中...'
- `NO_DATA`: '暂无内容'
- `ERROR`: '加载失败，稍等一下再试吧'
- `NO_NETWORK`: '检查一下网络，再试试看吧'
- `NO_SEARCH_RESULT`: '暂无搜索结果'
- `NO_MESSAGE`: '暂无内容'
- `NO_FOLLOWER`: '还没有关注的人'
- `NO_RECORD`: '暂无记录'
- `NO_COLLECTION`: '还没有收藏过内容'

默认`Loading`
