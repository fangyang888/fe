- `regular`: 红（#ff4d88）

## API

| 参数 | 说明               | 类型         | 默认值 |
|------|--------------------|--------------|--------|
| className | 类名 | `string` | -- |
| style | 样式 | `React.CSSProperties` | -- |
| type | 按钮类型 | `enum('primary', 'regular')` | `'primary'` |
| size | 按钮大小，默认 32 高，小开关 16 | `enum('large','small')` | `large` |
| defaultChecked | 初始是否选中 | `boolean` | `false` |
| checked | 指定当前是否选中，与 onChange 配合进行组件受控 | `boolean` | `false` |
| onColor | 开关开启状态的背景色 | `string` | -- |
| offColor | 开关开启状态的背景色 | `string` | -- |
| thumbColor | 开关的圆形按钮的背景色 | `string / number` | -- |
| disabledColor | 开关禁用状态的背景色 | `string` | -- |
| disabled | 是否禁用 | `boolean` | `false` |
| width | 开关宽度 | `string / number` | -- |
| height | 开关高度 | `string / number` | -- |
| thumbRect | 开关圆形按钮直径 | `string / number` | -- |
| thumbGap | 圆形按钮到开关的距离 | `string / number` | -- |
| onChange | 选项改变时回调，与 value 配合进行组件受控 | `(boolean) => void` | -- |

除了默认配置项，`div` 可以接收的所有 props，都会作用到组件根节点，如

- onMouseDown
- onMouseUp
