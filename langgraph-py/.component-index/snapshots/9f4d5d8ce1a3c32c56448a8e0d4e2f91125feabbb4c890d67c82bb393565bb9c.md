# SubscriptionButton

美柚订阅组件:

- 组件内已适配iphone手机底部高度，前端项目html需要添加 `<meta name="viewport" content="viewport-fit=cover">`
- 跳转协议无论前端页面还是客户端页面都通过web协议进行跳转，url为base64转过的参数
- 配置了 `image` 属性，内容区域会优先展示 `image`，`title`、`subtitle`、`description` 这几个属性不展示
- 组件最多可同时配置2个按钮，上方按钮根据是否配置 `topButton` 显示，下方按钮常显；如果只需要一个按钮，则使用常显按钮属性`buttonText`、`protocol`、`onButtonClick`、`buttonProps` 配置按钮相关属性

## 基本用法

SubscriptionButton 根据`title`、`subtitle`、`description`、`topButton`、`buttonText`下发的字段值形成多种卡片样式:

- 样式一：`title` + `subtitle` + `description` + `topButton` + `buttonText`
- 样式二：`title` + `description` + `buttonText`
- 样式三：`description` + `buttonText`
- 样式四：`buttonText`
- 样式五：`topButton` + `buttonText`

## 定义按钮

通过`onButtonClick`方法可以触发额外点击事件，例如：埋点；

通过 `buttonProps` 自定义按钮的样式和事件,常用场景例如：

- 按钮样式
- 自定义跳转协议时间

## 配置图片可点击、可关闭
内容区域配置 `image` 属性（图片区域默认不可点击），通过配置 `imageUrl` 属性可以支持点击图片跳转对应页面，通过配置 `imageClosable` 属性支持关闭图片（图片关闭后将只展示按钮）

<Alert type="info">
注意，组件会使用客户端协议 `map/set` 缓存被关闭的 `image`，因此需要配置 `sceneKey` 属性作为缓存 key 值，一旦手动关闭图片，下次不再展示。如果不需要图片关闭逻辑，可通过配置 `cacheImageClosed` 为 false，则图片会根据所配置的展示
</Alert>

## 配置支付按钮
通过 `topButton` 属性可以配置卡片上方按钮为支付按钮，组件内部会判断 `topButton.protocol` 属性是否含有字符串 `pay_button`，若是，则点击按钮会弹起支付弹窗，同时需要配置属性 `paymentProps`，会把该属性的配置传给 `PaymentPopup` 组件

*如果有支付弹窗，还需额外引入样式文件*

<code src='./demos/Payment.tsx' />

## 配置非支付按钮右上角展示标签和红包动效
通过 `tagText` 属性可以配置卡片非支付按钮展示标签
- 只配置 `tagText`，只展示标签
- 配置 `tagText` 和 `countDown`，则先展示红包动效，再展示标签，标签内容由 `tagText` 和 `countDown` 组合并进行倒计时
