# PaymentPopup

支付弹窗组件:
- 组件由2部分组成：loading + 支付弹窗，当 `visible` 为 `true` 时，有2种情况：
1. 属性 `productData` 有传入数据，则直接弹出支付弹窗
2. 属性 `productData` 未传入数据，则弹出 loading 并请求接口获取商品详情，待获取到数据关闭 loading 再弹出支付弹窗，点击立即支付跳转支付宝/微信进行支付

- 经测试，Android 手机会在美柚 APP 内直接打开支付宝的支付页面进行支付，iOS 手机则会跳转支付宝，支付完成回到美柚

*注意：`visible` 为 `true` 时，并不代表支付弹窗是显示状态，若需要支付弹窗显示时有额外操作，可通过配置 `drawerProps.onOpen` 属性*
