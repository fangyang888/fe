# NavBar

导航栏组件

根据原项目页面布局的滚动区域不同 NavBar 提供`position`设置不同页面布局:

- `relative`： 默认属性，nav与滚动区域不重叠
- `fixed`： 原布局nav在页面上层

<code src='./demos' phone />

## 基本用法

NavBar 具有三种类型`type`，显示不同的状态样式:

- `black`：  `F2F2F5`背景色和单箭头返回
- `white`： 文字和返回图会变为白色主题
- `gradient`： 渐变交互,页面上滑后，标题栏仍保持灰色,标题栏底部分割线跟随标题栏渐显(0.5px，色值`CCCCCC`)
  
默认`black`类型，显示`F2F2F5`背景色和单箭头返回

<code src='./demos/Base.tsx' />

## 页面滚动导航渐变

配置`type`为`gradient`时开启滚动渐变

页面上滑后，标题栏仍保持灰色,标题栏底部分割线跟随标题栏渐显(0.5px，色值`CCCCCC`)

- `scrollRef`为滚动元素
- `scrollDistance`为变为百分百灰色的距离，默认`96`
- `scrollOffsetTop`为开始变色的距离，默认`0`

（标题栏渐显的无需遵循8px全显规则）
