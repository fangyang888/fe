# LegacyStatusAlert

柚宝宝、医生端等app遗留 的加载 / 提示 / 异常 等缺省状态占位组件

<Alert type="info">
注意，非 full 模式下，LegacyStatusAlert 通过 `flex: 1` 撑满父容器，因此父容器需要是 `display: flex`。
</Alert>

<code src='./demos' phone />

## 基本用法

LegacyStatusAlert 具有四种类型，具备不同的状态样式:
- `NONE`: 无样式
- `LOADING`: '努力加载中...'
- `NO_DATA`: '暂无内容'
- `NO_NETWORK`: '检查一下网络，再试试看吧'

默认`Loading`

## Full 模式

在有些场景下，我们需要扣除导航栏以及底部安全区域的高度，我们可以通过 full 属性来自动预留这些空间，如果是沉浸式，则 `full = { pure: true }` 否则为 `full = { pure: false }`
