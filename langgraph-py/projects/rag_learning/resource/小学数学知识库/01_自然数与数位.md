# 自然数与数位

自然数可以用来表示物品的个数。没有物品时，可以用 0 表示。认识大数时，先看每个数字在哪一个数位上。

## 数位与十进制

从右向左依次是个位、十位、百位、千位、万位等。相邻两个数位的计数单位相差 10 倍。一个数字在不同数位上表示不同的大小。比较两个自然数时，位数多的较大。位数相同就从最高位起逐位比较。

## 例题与易错点

`40506` 读作四万零五百零六。数字 4 在万位，表示 40000。数字 5 在百位，表示 500。它可以写成 `40000 + 500 + 6`。

`40506` 和 `45006` 都是五位数。万位都是 4，千位分别是 0 和 5，所以 `40506 < 45006`。写数时要用 0 占住空的数位。
