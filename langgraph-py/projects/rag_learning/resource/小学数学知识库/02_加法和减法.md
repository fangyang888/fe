# 加法和减法

把几部分合起来可以用加法。求两个数相差多少，或者从总数里去掉一部分，可以用减法。

## 笔算与验算

多位数加减时把相同数位对齐，从个位算起。加法中某一位满十，就向前一位进 1。减法中某一位不够减，就向前一位借 1，当作本位的 10。前一位是 0 时，继续向更高位借。

## 例题与易错点

`304 + 178 = 482`。个位 `4 + 8` 得 12，写 2 并向十位进 1。用 `482 - 178 = 304` 可以验算。

`482 - 196 = 286`。用 `286 + 196 = 482` 检查结果。列竖式时 196 的个位和 482 的个位对齐，借位后记得把借出的一位减 1。
