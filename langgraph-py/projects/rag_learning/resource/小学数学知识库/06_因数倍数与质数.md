# 因数、倍数与质数

在正整数范围内，如果 `a × b = c`，就说 a 和 b 是 c 的因数，c 是 a 和 b 的倍数。因数和倍数描述的是两个数之间的关系。

## 判断特征

个位是 0、2、4、6、8 的整数是 2 的倍数。个位是 0 或 5 的整数是 5 的倍数。各位数字之和是 3 的倍数时，原数是 3 的倍数。

质数大于 1，只有 1 和它本身两个正因数。合数大于 1，至少有三个正因数。1 既不是质数，也不是合数。

## 例题与易错点

12 的正因数是 1、2、3、4、6、12。12 和 18 的最大公因数是 6，最小公倍数是 36。把总数平均分组常需要找因数，同步重复的事件常需要找公倍数。
