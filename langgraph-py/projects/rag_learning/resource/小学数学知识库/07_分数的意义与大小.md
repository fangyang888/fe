# 分数的意义与大小

把一个整体平均分成若干份，用分数表示其中的一份或几份。分母说明平均分成几份，分子说明取了几份，分母不能是 0。

## 等值分数、约分和比较

分子和分母同时乘或除以同一个非零整数，分数的大小不变，除法要使结果仍为整数。`2/4 = 1/2` 就是约分后的结果。分母相同，分子大的分数较大。正分数的分子相同，分母较小的分数较大。

## 例题与易错点

比较 `2/3` 和 `3/4`。把它们通分成 `8/12` 和 `9/12`，可知 `3/4` 较大。

比较两块蛋糕实际吃了多少时还要看整体大小。大蛋糕的 `1/2` 和小蛋糕的 `1/2` 表示相同的比例，实际分量可能不同。
