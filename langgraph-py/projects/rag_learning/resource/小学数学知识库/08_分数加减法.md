# 分数加减法

分数相加减前，要先确认每一份的大小一样。分母相同就可以直接处理份数，分母不同要先通分。

## 同分母和异分母计算

同分母分数相加减，分母不变，分子相加减。分母不变的原因是每一份大小保持不变。`1/6 + 2/6 = 3/6` 表示每份仍是六分之一，合起来共有 3 份。

异分母分数先通分，再按同分母规则计算。结果能约分时可以化成最简分数。

## 例题与易错点

`5/8 - 2/8 = 3/8`。`1/2 + 1/3 = 3/6 + 2/6 = 5/6`。最小公倍数可以作为公分母。

把 `1/6 + 2/6` 算成 `3/12` 是把分母也相加了。画一个平均分成 6 格的长条，先涂 1 格，再涂 2 格，能看到一共涂了 3 格。
