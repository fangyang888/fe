# 小数的意义与运算

小数点右边从左向右依次是十分位、百分位、千分位。`0.36` 也可以写成 `36/100`，表示三十六个百分之一。

## 比较和计算

比较小数时，从整数部分起，再依次比较十分位、百分位等。小数末尾添 0 或去掉 0，数值相同。小数加减时把小数点对齐。小数乘法先按整数算，积的小数位数按因数的小数位数之和定位，再按需要化简。小数除法中，可把被除数和除数同时乘以 10、100 或 1000 等，选择能使除数变成整数的倍数。

## 例题与易错点

`0.8 = 0.80`，所以 `0.8 > 0.75`。`1.25 + 0.8 = 2.05`，列竖式时写成 `1.25 + 0.80` 便于对齐。

`1.2 × 0.3 = 0.36`。`4.2 ÷ 0.6 = 42 ÷ 6 = 7`，扩大除数时，被除数也扩大同样的倍数。
