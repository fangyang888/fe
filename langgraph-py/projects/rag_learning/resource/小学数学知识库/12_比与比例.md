# 比与比例

两个量相除，可以写成比。`3 : 2` 的前项是 3，后项是 2，比值是 `3 ÷ 2`。两个比相等的式子叫作比例。

## 化简比和比例关系

比的前项和后项同时乘或除以同一个非零数，比值不变。比较同类量时，先统一单位。在比例 `a : b = c : d` 中，`a × d = b × c`。两种量的比值固定时成正比例，乘积固定时成反比例。

## 例题与易错点

调果汁时，浓缩汁与水按 `1 : 4` 混合。总量是 500 毫升，共 5 份，浓缩汁有 100 毫升，水有 400 毫升。

图上 2 厘米表示实际 20 米。把 20 米化成 2000 厘米，比例尺是 `2 : 2000 = 1 : 1000`。先把两边换成相同单位再化简。
