# 总体路线和能力目标

## 目标定义

本项目中的“掌握Python”分为四级：

1. **会写**：能独立写小函数、类、异步代码和测试。
2. **会组织**：能划分API、Service、Repository、Schema和基础设施。
3. **会排错**：能根据日志、异常、测试和数据库状态定位问题。
4. **会上线**：能处理配置、超时、并发、权限、部署、监控和回滚。

24周的目标是达到第4级的初步能力。真正精通需要继续维护系统、阅读优秀源码并处理真实故障。

## 24周建议

| 周数 | 内容 | 里程碑 |
| --- | --- | --- |
| 1～4 | Python核心 | 三个纯Python Tool和测试 |
| 5～6 | 工程化 | 质量检查全部通过 |
| 7～9 | FastAPI/Pydantic | 请求、响应、意图和事件Schema |
| 10～12 | MySQL/SQLAlchemy | 会话历史持久化 |
| 13 | Redis | 短期状态和幂等 |
| 14～17 | LLM与Agent | 可运行的Python客服Agent |
| 18～20 | SSE与生产能力 | 前端可接收完整事件流 |
| 21～24 | 双轨验证和上线 | 灰度迁移、可随时回滚 |

## 明确边界

- React前端保留。
- NestJS继续负责非Agent接口。
- MySQL表和历史数据尽量复用。
- `/api/agent/*`逐步切到Python服务。
- TypeScript Agent稳定运行到Python完成验收之后。

## 学习比例

- 60%：亲手编码和调试。
- 20%：测试和复盘。
- 15%：阅读官方资料和当前项目代码。
- 5%：整理自己的笔记。
