# 列表、元组、字典和集合

## 四种容器

- `list`：有顺序、可修改，适合消息列表。
- `tuple`：有顺序、通常表示固定结构或不可修改结果。
- `dict`：键值映射，适合配置、实体字段和JSON对象。
- `set`：元素唯一，适合去重和成员判断。

```python
messages = [{"role": "user", "content": "你好"}]
allowed_tools = {"calculator", "get_current_time"}
entities = {"product_name": None, "budget_max": 100}
```

## 必须掌握

索引和切片、`append`、`extend`、`get`、`items`、成员判断、浅拷贝与可变对象共享。

## 常见坑

- 函数默认参数写成`items=[]`导致多个调用共享同一个列表。
- 直接修改从别处传入的字典，造成隐藏副作用。
- 误以为`set`保持业务顺序。

## 练习

接收若干工具名称，去重后保持第一次出现的顺序，拒绝空字符串。

## 验收

能够根据“顺序、唯一性、可变性、查找方式”选择正确容器，并解释默认可变参数问题。
