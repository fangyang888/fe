# Depends与应用装配

## 依赖注入解决什么

路由需要配置、数据库Session和Service，但不应该在每次请求中散落创建代码。FastAPI的`Depends`可以描述请求级依赖。

不要机械模仿NestJS：Python中纯函数和简单对象可以直接使用，只有需要生命周期、替换或资源管理的依赖才进入Depends。

## 生命周期建议

- Settings：进程级复用。
- 模型客户端：进程级复用。
- 数据库AsyncSession：请求级。
- Redis客户端：进程级连接池。
- 当前用户：请求级。

## 练习

把健康接口的配置改成规范的Depends形式，并在测试中覆盖替换依赖。

## 验收

能解释依赖的创建时间、释放时间，以及为什么测试应该替换依赖而不是访问真实模型。
