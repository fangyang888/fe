# SQL、表关系和约束

## 必学SQL

`SELECT`、`INSERT`、`UPDATE`、`DELETE`、`WHERE`、`ORDER BY`、`LIMIT`、聚合和JOIN。

## 数据建模

会话与消息是一对多关系：一个conversation拥有多条message。主键标识一行；外键保证关联；唯一约束保证幂等；非空约束阻止不完整数据。

计划复用：

- Agent会话表
- Agent消息表
- 商品与分类表

## 安全

所有用户值通过参数绑定传入，禁止字符串拼接SQL。模型提供的userId、orderNo和权限声明都不可信。

## 练习

手写SQL：创建会话、插入用户消息、插入回答、按时间查询最近100条消息。

## 验收

能解释主键、外键、唯一约束和普通索引分别保证什么，删除父记录可能发生什么。
