# 索引、事务和并发

## 索引

索引加快符合前缀规则的查询，但增加写入和存储成本。学习联合索引顺序、覆盖索引和`EXPLAIN`。

消息常见查询条件是conversationId加排序字段；幂等查询是conversationId、clientMessageId和role组合。

## 事务

一次用户回合包含多个相关写入。成功时commit，任一步失败时rollback，避免出现一半完成的数据。

必须理解：原子性、一致性、隔离性、持久性，以及并发请求可能导致的重复插入和丢失更新。

## 练习

设计消息幂等唯一约束，并分析两个相同clientMessageId请求同时到达时会发生什么。

## 验收

能使用数据库约束作为最后防线，而不是只依赖“先查询再插入”的应用逻辑。
