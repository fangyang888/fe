# Relationship与查询性能

## Relationship

Relationship用于对象间导航，但不等于数据库外键。理解一对多、双向关系、级联规则和加载策略。

## 常见性能问题

- N+1：先查会话，再对每个会话单独查消息。
- 无限制加载全部历史。
- 在异步代码中触发隐式懒加载。
- 对未命中索引的字段排序和过滤。
- 把大JSON或完整消息无条件读出。

## 练习

比较selectinload、joinedload和显式查询；为“最近100条消息”查看生成SQL和`EXPLAIN`。

## 验收

能够从日志中识别N+1，并根据数据规模、分页和返回结构选择加载方式。
