# Alembic迁移

## 目的

Alembic把数据库结构变化保存成可审查、可重复执行的版本，而不是直接手改生产数据库。

学习：初始化、revision、upgrade、downgrade、autogenerate、迁移历史和数据迁移。

## 安全规则

- 自动生成只提供草稿，必须人工审查。
- 删除列、改类型、加非空约束前先评估已有数据。
- 大表变更要评估锁表时间。
- 每个迁移要有明确升级路径，关键变更要演练回滚。

## 练习

为测试表增加一个可空字段，再分两个迁移完成数据回填和非空约束，而不是一步强制修改。

## 验收

能在空数据库升级到最新，也能从当前版本升级；迁移不会意外修改无关商城表。
