# MySQL集成测试

## 为什么不用SQLite代替全部测试

SQLite和MySQL在类型、并发、JSON、约束和SQL语法上有差异。SQLite可以做少量快速测试，但关键Repository必须在MySQL上验证。

## 测试原则

- 使用独立测试数据库。
- 每个测试隔离数据。
- 不访问开发或生产数据库。
- 测试开始前校验数据库名称。
- 覆盖唯一约束、事务回滚、并发幂等和分页顺序。

后期安装Docker后，可以使用容器启动固定版本MySQL，让CI与本地一致。

## 练习

写集成测试：重复写入相同clientMessageId只产生一个用户消息；回答保存失败时用户消息状态正确更新。

## 验收

测试可重复运行、不依赖执行顺序、失败后不留下污染数据。
