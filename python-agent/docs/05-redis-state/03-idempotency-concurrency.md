# 幂等、原子性和并发

## 幂等

同一个clientMessageId重复请求，不应该重复扣费、重复写消息或启动多个不可控任务。

Redis可以快速拦截重复执行，但MySQL唯一约束仍是最终防线。不能因为Redis存在就删除数据库约束。

## 并发问题

- 检查后写入之间存在竞争窗口。
- 锁必须有TTL和唯一token。
- 解锁必须确认token属于自己。
- 进程崩溃后锁不能永久存在。
- 长任务需要续期或采用其他状态机设计。

## 练习

设计`pending → completed/failed`幂等状态；两个请求并发到达时只有一个执行，另一个复用结果或得到明确状态。

## 验收

能够说明Redis锁不是万能分布式事务，并为并发行为写测试。
