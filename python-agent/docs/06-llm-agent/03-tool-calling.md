# Tool Calling与安全Schema

## Tool组成

Tool = 普通函数 + 名称 + 给模型的说明 + 参数Schema。模型只决定是否调用和提供候选参数，真正执行的是后端代码。

## 工具设计规则

- 名称稳定、职责单一。
- 描述说明“何时使用”，避免能力重叠。
- 参数限制长度、范围、枚举和格式。
- 工具返回结构稳定且大小受限。
- 设置超时并分类错误。
- 记录工具名和耗时，不记录敏感结果。
- 数据库查询参数化。

## 学习迁移

先包装第1章的calculator、time和text函数，再增加只读商品查询。不要一开始开放退款、删除和修改订单。

## 验收

非法参数无法进入工具核心函数；工具异常不会导致进程崩溃；普通闲聊不会误调工具。
