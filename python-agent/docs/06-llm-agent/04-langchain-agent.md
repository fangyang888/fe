# LangChain Agent

## 学习内容

使用LangChain Python的现代Agent API装配模型、工具、系统提示和Checkpointer。

理解一次循环：

1. 用户消息进入模型。
2. 模型回答或产生tool call。
3. 框架验证并执行工具。
4. 工具结果返回模型。
5. 模型继续判断，直到最终回答或达到限制。

## 必须设置的边界

- 最大步骤数。
- 整体超时和单工具超时。
- 有限重试。
- 工具白名单。
- 上下文长度控制。
- 取消信号。
- 最终输出解析。

## LangGraph何时使用

只有出现人工审批、跨请求暂停恢复、复杂分支循环或持久长任务时，才编写自定义图。普通工具Agent先使用预构建能力。

## 验收

能够画出一次工具循环并定位每一步日志，不能只会复制`create_agent`示例。
