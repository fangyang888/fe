# 权限、安全和人工确认

## 永不信任模型提供的身份

当前用户必须来自认证上下文，而不是Tool参数。订单查询必须验证订单属于当前用户。

## 风险分级

- 低风险：时间、计算、商品只读查询，可自动执行。
- 中风险：查看个人订单，需要认证和归属校验。
- 高风险：退款、取消、改地址、支付，需要二次确认或人工审批。

## 防护

- 最小权限数据库账号。
- Tool白名单和参数Schema。
- Prompt Injection不能提升权限。
- 写操作使用幂等键和审计记录。
- 人工确认内容要包含动作、对象和影响。
- 日志脱敏。

## 验收

测试用户无法查询他人订单；模型即使要求绕过规则也不能改变后端权限判断。
