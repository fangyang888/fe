# 异步流、取消、超时和背压

## 异步流

FastAPI使用异步生成器逐条产生SSE。客户端断开后，应尽快取消模型和工具任务并释放资源。

## 三种时间限制

- 连接级：整次请求允许多久。
- 模型级：单次模型调用允许多久。
- 工具级：一个工具允许多久。

重试必须有限、有退避，并只针对可重试错误；不能因重试产生重复写操作。

## 背压

客户端读取慢时，服务端不能无限积累事件。事件写入需保持顺序，队列要有界，断开后停止生产。

## 练习

用fake模型模拟慢输出、客户端断开、工具超时和持久化后连接关闭，验证最终数据库状态。

## 验收

不存在无限pending；取消不会留下未释放Task；已持久化回答不会被错误标记为failed。
