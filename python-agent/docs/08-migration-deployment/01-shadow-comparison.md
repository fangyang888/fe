# 双轨、影子流量与结果对比

## 迁移阶段

1. Python只运行单元测试和契约测试。
2. 开发环境手工切换。
3. 影子执行：真实请求仍由旧版回答，Python只生成内部对比结果。
4. 小流量灰度。
5. 全量切换。
6. 观察期结束后再停止旧Agent。

## 对比内容

- HTTP状态码。
- 响应字段和类型。
- 意图和实体。
- Tool选择。
- SSE事件类型与顺序。
- 数据库写入。
- 延迟、错误率和成本。

自然语言文本不适合逐字比较，应比较结构、事实、工具结果和安全规则。

## 验收

建立固定回归数据集，失败案例可重复运行，并能区分模型随机差异与程序缺陷。
