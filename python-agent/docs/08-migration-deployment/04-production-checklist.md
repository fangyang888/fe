# 生产检查清单

## 配置与安全

- [ ] Secret只来自安全环境，不进入Git和镜像。
- [ ] 生产关闭调试模式。
- [ ] CORS、认证和权限配置正确。
- [ ] Tool写操作有幂等与审批。
- [ ] 日志脱敏。

## 可靠性

- [ ] 模型、数据库、Redis和Tool都有超时。
- [ ] 重试有限且不会重复写入。
- [ ] 数据库连接池和Redis连接池有上限。
- [ ] 客户端断开会取消后台任务。
- [ ] 健康检查不泄露敏感信息。

## 数据

- [ ] Alembic迁移已在副本演练。
- [ ] 新旧版本Schema兼容。
- [ ] 备份与恢复已验证。
- [ ] 消息幂等唯一约束存在。

## 可观测与回滚

- [ ] 错误率、延迟和首字时间有监控。
- [ ] runId能关联完整调用链。
- [ ] 灰度阈值明确。
- [ ] Nginx可快速切回NestJS。
- [ ] 回滚演练通过。

只有所有关键项有证据通过，才能删除旧TypeScript Agent代码。
