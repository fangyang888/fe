# SCSS 重构验收

目标是改善样式维护性，同时保持已有页面在被检查状态下的外观。修改前截图是回归基准，不代表原页面符合设计规范。本流程不授权调整视觉设计、升级主题依赖或迁移整个仓库。

## 确定范围与变量归属

先读项目规则、目标模块构建配置、现有变量文件及主题规范，检查目标 SCSS 的引用关系。保留用户已有修改，不重置代码来制造基准。

- 已有含义一致且当前作用域可用的变量，优先复用；值相同但用途不同不能直接合并。
- 组件内部共用值放当前 SCSS；跨组件且含义稳定的值才提升到模块变量文件。遵循现有命名与导入方式，不顺手迁移 `@import` / `@use`。
- 主题颜色遵循已有 CSS 自定义属性和主题作用域；尺寸等静态值可用 Sass 变量。不要将动态 `var()` 固化为浅色值，也不要把需要 Sass 颜色运算的值直接替换成 `var()`。
- 不改原值、单位、选择器、声明顺序、权重或媒体查询；不把相近颜色、间距四舍五入成统一值。单次使用的布局数值无需全部变量化。
- 新变量文件只放变量、函数或 mixin 定义，避免反复导入时输出重复 CSS。公共变量变更必须检查全部引用位置。

## 修改前保存基准

1. 列出本次涉及的页面和状态，例如默认、选中、禁用，以及原有的浅色/暗黑主题。只覆盖实际存在且受本次修改影响的状态；检查不到的项目记录为未验证。
2. 为每个页面、状态和视口复制一份 [重构用例](../../../cases/scss-refactor.example.json)。替换 URL、选择器和路径；示例 URL 的状态参数只是占位，CLI 不会自动点击或设置主题。使用项目已有测试入口或可重复的状态准备方式，Mock 遵循项目规范。
3. 在改代码前启动真实页面，固定数据、浏览器、视口、DPR、字体、主题和截图范围。每个用例的 `designImage` 指向本次重构专属的 `baseline/<状态>.png`，`outputDir` 指向独立的修改后目录；不得互相覆盖。
4. 用现有 `capture` 保存基准。以下命令与示例的视口截图配置匹配，将占位路径和 URL 换成真实值：

```bash
node "<插件根目录>/scripts/run.mjs" capture --url "http://127.0.0.1:3000/example?visual_state=default" --output "<项目>/visual-qa/scss-refactor/baseline/default.png" --width 375 --height 812 --dpr 1 --browser-channel chrome --wait-for ".example-page"
```

`capture` 不是 `capture --case`：实际使用时必须与用例同步 URL、viewport、browserChannel 和等待条件。如果需要完整页面或 CLI 未暴露的配置，使用现有 `readVisualCase` 与 `captureH5Screenshot` API 读取同一用例截图，不能假设 CLI 支持未实现的参数。长页面应覆盖受影响的屏外内容，不能只验收首屏。

5. 查看基准并核对状态，保存源码版本及未提交改动说明、URL、环境、状态准备步骤和截图 SHA-256 到项目验收目录的 `baseline.md`。修改前再捕获一次到独立临时路径，使用相同阈值对比以检查可重复性；失败先处理数据、字体或动画不稳定问题，不能把重构后的截图补作基准。

没有可用的修改前基准时，可以进行源码整理，但必须报告视觉回归未验证，不能宣称外观不变。

## 修改与复验

按上述归属规则小范围替换，运行目标模块的实际 Sass 编译或本地构建。纯静态 Sass 变量抽取优先比较编译前后的 CSS，排除 sourcemap 等元数据后检查声明是否等价；编译成功不能代替浏览器验收。

每个状态执行完整复验：

```bash
node "<插件根目录>/scripts/run.mjs" verify --case "<项目>/visual-qa/scss-refactor/default.json" --mode final --no-cache
```

重构最终验收不使用 `--changed-only` 或旧验收结果。示例采用严格视觉阈值，需在修改前确认环境可重复；不为通过而放宽阈值、替换基准或增加遮罩。已有结构、DOM 契约和 CSS 检查保留；历史问题单独报告，不趁变量抽取重写布局。复验时校验基准哈希未变。

## 交付

报告变量映射（原值、变量名、组件或模块作用域、替换位置）、构建结果、各页面/状态的对比指标及截图/报告路径，并列出未验证状态。只有全部计划状态完成才能报告本次范围内通过；截图通过不等于所有交互或所有页面通过。本流程复用现有报告，变量映射和覆盖表由代理整理，不声称 CLI 已实现自动 SCSS 分析或状态遍历。
